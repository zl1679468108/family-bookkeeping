## 14:41 - 聚焦容器功能（Spotlight）

**需求**：概览页预算超支提醒点击后跳转到预算页面，自动滚动并高亮对应分类行。

**实现**：
1. 创建 `frontend/src/hooks/useFocusItem.ts` — 通用 Hook
   - 从 URL 中读取 `?focus=xxx` 参数
   - 用 `requestAnimationFrame` 等待 DOM 渲染完成后 `scrollIntoView({ behavior: 'smooth', block: 'center' })`
   - 添加 `spotlight--focused` class 触发高亮动画
   - 2.5s 后自动移除高亮并清除 URL 参数

2. 全局 CSS（`globals.css`）添加 spotlight 动画
   - `spotlightPulse`: box-shadow 脉冲（2px→3px + 光晕渐大）
   - `spotlightBorderGlow`: border 颜色呼吸
   - 深色模式适配（`[data-theme="dark"]` 下有独立动画）

3. 修改 `Budgets.tsx`
   - 集成 `useFocusItem({ getTargetSelector: (id) => \`[data-focus="${id}"]\` })`
   - 每行添加 `data-focus={catKey}` 属性
   - 匹配时 className 追加 `spotlight--focused`

4. 修改 `Dashboard.tsx`
   - 左侧"管理预算"按钮：`navigate('/budgets?focus=xxx')`
   - 右侧"查看预算详情"按钮：同上
   - 左侧超支标签 span：可点击跳转
   - 右侧预警列表 div：每个条目可点击跳转
   - 全部 hover 时有 opacity 反馈

**用户交互流**：Dashboard 点击「餐饮超支」→ `/budgets?focus=food_delivery` → 自动滚动到餐饮行（居中）+ 蓝色脉冲高亮 2.5s

**QA**：tsc --noEmit 零错误通过
