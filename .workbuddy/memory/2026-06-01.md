### 日期格式：移除"今天/昨天"相对日期
- AddTransaction.tsx `formatDate` 只显示精确日期 `M月D日`，不再显示"今天"/"昨天"

### 地图加载：AMap SDK 加载方式对齐 PC 端
**根因**: mobile LocationPicker 用旧的 `callback=_onAmapLoad` 方式加载 SDK，与 PC 端 `script.onload` 方式不一致，导致加载失败

**修复**:
- `loadAmap` 改用 `script.onload`（与 PC 端 `amapManager.ts` 一致）
- 添加 `_AMapSecurityConfig` 安全密钥支持（通过 `VITE_AMAP_SECRET` 环境变量）
- SDK URL 预加载插件 `AMap.PlaceSearch,AMap.Geocoder`
- 修复 `useEffect` 依赖数组：添加 `amapKey, amapSecret, amapVersion, initMap`
- 添加 `cancelled` flag 防止组件卸载后的状态更新
- `initMap` 添加 `reverseGeocode` 依赖，`handleRetry` 提取为 `useCallback`
- 搜索结果的 key 改用 `lat-lng-idx` 避免纯索引 key 问题
- TypeScript 检查: ✅ 零错误
