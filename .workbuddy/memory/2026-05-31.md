## BugFix: mobile Transactions.tsx — 类型切换数据不展示（重构方案）

- **根因**: react-query v5 默认 `structuralSharing: true`。当切换类型筛选后新旧结果值相同时复用旧引用，导致 `useEffect([data])` 不触发
- **方案演进**: 用户拒绝 `structuralSharing: false` 的 workaround，要求用更干净的逻辑
- **最终方案**: 去掉 `useState(allTransactions)` + `useEffect([data])` 模式，改为 render 内 ref 推导
  - `pagesRef`（Map<page, Transaction[]>）在 render 阶段 inline 存取，filter 变化时 inline 重置
  - `allTransactions` 用 `useMemo([page, data, isLoading, isFetching])` 从 pagesRef 推导
  - 完全绕过引用对比问题，不依赖 structuralSharing 行为
- **改动**:
  - 删除 `allTransactions` state + `setHasMore` state + 两个数据同步 useEffect
  - 新增 `pagesRef`/`lastFilterKeyRef` + inline 重置/存储/推导逻辑
  - 删除 `structuralSharing: false`
  - 简化 reset effect（只 setPage(1)）、简化 delete mutation（只 invalidateQueries）
- **TypeScript 检查**: ✅ 零错误

## BugFix: 现金流日历 — 金额"k"缩写 + 交易计数不一致

**问题1**: Calendar/index.tsx 的 `formatShortAmount` 将 ≥1000 的金额缩写为 "k"（如 9000 → "9.0k"）
**修复**: 替换为 `formatCompactAmount`，使用 `toLocaleString('zh-CN')` 显示完整数值（带千分位逗号）

**问题2**: Transactions 页面无默认日期过滤 → 显示所有时间12笔；Calendar 按月过滤 → 只显示本月11笔
**根因**: filter 初始化的 startDate/endDate 默认空字符串，不加日期过滤
**修复**: 导入 date-fns，filter 默认 startDate=当月1号、endDate=今天（URL 参数优先）

**修改文件**:
- `frontend/src/pages/Calendar/index.tsx` — 替换 formatShortAmount → formatCompactAmount
- `frontend/src/pages/Transactions/index.tsx` — 添加 date-fns 导入，filter 默认本月范围
