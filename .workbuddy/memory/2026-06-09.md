## Admin 管理后台数据绑定修复

### 问题
用户管理、交易监控页面接口有数据但列表不渲染（显示"共 0 个用户/0 笔交易"）。

### 根因
后端 `ResponseInterceptor` 会提取 `payload.data` 作为响应 data。AdminService 返回 `{ data: [...], total }` 时，拦截器把内层 `data`（数组）提取为外层 data，导致分页信息丢失。

### 修复内容
- `backend/src/admin/admin.service.ts`：
  - `getUsers` 返回字段 `data` → `users`
  - `getTransactions` 返回字段 `data` → `transactions`
- `frontend/src/services/adminApi.ts`：同步更新类型定义 `UsersListResponse.data` → `users`，`AdminTransactionsResponse.data` → `transactions`
- `frontend/src/pages/Admin/AdminUsers/index.tsx`：`data?.data` → `data?.users`
- `frontend/src/pages/Admin/AdminTransactions/index.tsx`：`data?.data` → `data?.transactions`

### 需要用户操作
- 重启后端服务（`npm run start:dev`）使 Service 改动生效

## 任务10：修复 TabBar 图标显示错误

**问题**：截图显示 TabBar 中"流水"和"统计"在未选中状态下显示成了**绿色房子图标**，而非各自应有的列表/柱状图图标，且颜色应为灰色。

**根本原因**：`Icon` 组件的 `IconName` 类型和 `getIconFile` map 中未包含 `-gray` 后缀的图标名称（如 `"transactions-gray"`、`"statistics-gray"`）。当 TabBar 传入这些名称时，`map[name]` 返回 `undefined`，fallback 到 `"home"`，导致加载了 `home.svg`（绿色房子）。

**修复内容**：
- `src/components/Icon/index.tsx`：
  - `IconName` 类型扩展，新增 `"home-gray"`、`"transactions-gray"`、`"statistics-gray"`、`"profile-gray"`
  - `getIconFile` map 同步添加 `-gray` 版本的映射
  - `getSvgPath` 简化，移除 `isGray` 参数，直接按 `name` 查找对应 SVG 文件

**编译状态**：
- `tsc --noEmit` 零错误 ✅
