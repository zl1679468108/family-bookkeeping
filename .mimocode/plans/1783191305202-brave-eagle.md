# 预算页面卡片样式统一 + 筛选栏位置调整

## 问题分析

四个页面（账本、分类、模板、预算）的外层大卡片样式不一致：

| 页面 | 外层容器 | CardHeader | 内容区 padding |
|------|----------|------------|----------------|
| 账本 | `<Card>` → `dash-card dash-card--md` | `<CardHeader title="我的账本">` | 20px |
| 分类 | `<Card>` → `dash-card dash-card--md` | `<CardHeader title="分类管理">` | 20px |
| 模板 | `<div className="dash-card">` 直接用 class | `<CardHeader title="交易模板">` | 无 padding（内容紧贴边框） |
| 预算 | `<Card>` → `dash-card dash-card--md` | `<CardHeader title="预算明细" subTitle={dropdown}>` | 20px |

**核心差异**：
1. 模板页用 `dash-card` 而非 `<Card>` 组件，没有 padding
2. 预算页的 `subTitle`（月份下拉）在标题下方（`card-header-text` 是 column 布局），用户要求放到标题右边同一行
3. `card-header-text` 的 `flex-direction: column` 导致 title 和 subTitle 上下排列

## 修改方案

### 1. 统一模板页外层容器
- **文件**: `frontend/src/pages/Templates/index.tsx`
- 将 `<div className="dash-card">` 改为 `<Card>` 组件

### 2. 预算页筛选栏放到标题右边
- **文件**: `frontend/src/pages/Budgets/index.tsx`
- 将 `subTitle` 中的 DropdownSelect 移到 `CardHeader` 的 `action` 区域，与保存按钮并排
- 或者用自定义 header 布局，让标题和下拉在同一行

### 3. 修改 CardHeader 支持水平布局 subtitle
- **文件**: `frontend/src/components/ui/Card/index.tsx` + `index.scss`
- 给 CardHeader 增加 `compact` 模式或修改 `card-header-text` 为 `flex-direction: row` + `align-items: center`
- 或者在预算页不用 subTitle，直接自定义 header

### 推荐方案：预算页自定义 header
不改 CardHeader 全局行为（会影响其他页面），而是在预算页用 flex 布局：
```
<div className="card-header" style={{ flex-direction: row }}>
  <div style={{ display: flex, alignItems: center, gap: 12px }}>
    <h3>预算明细</h3>
    <DropdownSelect ... />
  </div>
  <div>保存按钮</div>
</div>
```

## 具体改动

### 文件 1: `frontend/src/pages/Templates/index.tsx`
- 第 48 行: `<div className="dash-card">` → `<Card>`
- 添加 import: `import { Card } from '../../components/ui/Card'`

### 文件 2: `frontend/src/pages/Budgets/index.tsx`
- 将 CardHeader 的 subTitle 移除
- 用自定义 flex header 替代，让标题和下拉在同一行
- 保存按钮保持在右侧

### 文件 3: `frontend/src/pages/Budgets/index.scss`
- 添加 `.budget-header` 样式（flex, align-items: center, justify-content: space-between）
