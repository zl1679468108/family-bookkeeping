# 02-模块功能

## 模块总览

### 前端模块（React）

| 模块名称 | 路径 | 主要功能 |
| :--- | :--- | :--- |
| 仪表板 | `/` | 财务概览、统计卡片、最近交易 |
| 交易记录 | `/transactions` | 交易列表、筛选查询 |
| 统计报表 | `/reports` | 图表分析、分类统计、导出功能 |
| 添加交易 | `/add` | 新建交易记录、图片识别 |
| 用户认证 | `/login`, `/register` | 用户登录、注册、密码找回 |

### 后端模块（NestJS）

| 模块名称 | 路径 | 主要功能 |
| :--- | :--- | :--- |
| 交易管理 | `/api/transactions` | 交易的增删改查 |
| 数据导出 | `/api/export` | Excel/PDF 文件生成 |
| 健康检查 | `/api/health` | 服务状态检查 |
| 用户认证 | `/api/auth` | 用户注册、登录、密码重置 |

## 已有功能（从菜单入手）

### 0. 用户认证模块 (`Auth`)

**功能定位**：实现用户注册、登录、密码找回等完整认证流程

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 用户注册 | 邮箱/用户名/密码注册 | 密码强度验证 |
| 用户登录 | 邮箱+密码登录 | 支持 JWT 认证 |
| 密码重置 | 通过邮件验证重置密码 | 发送重置链接到邮箱 |
| 用户信息管理 | 查看和修改用户信息 | 多用户数据隔离 |
| 会话管理 | 登录状态保持和退出 | token 过期处理 |

**实现功能**：
- 用户注册和登录
- JWT 令牌认证
- 密码哈希存储（bcrypt）
- 密码重置流程
- 登录状态管理
- 多用户数据隔离

---

### 1. 仪表板模块 (`Dashboard`)

**功能定位**：提供用户财务状况的快速概览

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 余额统计 | 展示当前账户余额 | 显示所有收支后的净额 |
| 收入统计 | 展示累计总收入 | 统计所有收入类型交易 |
| 支出统计 | 展示累计总支出 | 统计所有支出类型交易 |
| 最近交易 | 展示最近5条交易记录 | 按时间倒序排列 |
| 快捷操作 | 提供快速导航按钮 | 跳转报表页、添加交易页 |

**实现功能**：
- 实时统计账户余额、总收入、总支出
- 展示最近交易记录
- 响应式设计适配不同设备
- 加载状态反馈和错误处理

### 2. 交易记录模块 (`Transactions`)

**功能定位**：管理和查询所有交易记录

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 交易列表 | 展示所有交易记录 | 支持分页或滚动加载 |
| 类型筛选 | 按收入/支出筛选 | 支持全部、收入、支出三种选项 |
| 分类筛选 | 按分类筛选交易 | 根据交易类型动态加载分类选项 |
| 快捷添加 | 添加新交易入口 | 跳转至添加交易页面 |

**实现功能**：
- 交易列表展示和排序
- 按类型（收入/支出）筛选
- 按分类筛选交易
- 支持搜索功能
- 现代界面设计和响应式布局

### 3. 统计报表模块 (`Reports`)

**功能定位**：提供数据可视化分析

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 支出趋势图 | 展示支出随时间变化趋势 | 支持时间范围选择（6个月/3个月/1年） |
| 支出分类饼图 | 展示各分类支出占比 | 直观展示消费结构 |
| 分类金额统计 | 展示各分类具体金额 | 显示金额和占比百分比 |
| 导出 Excel | 导出交易数据为 Excel | 支持筛选导出 |
| 导出 PDF | 导出交易数据为 PDF | 支持筛选导出 |

**实现功能**：
- 支出趋势图表（折线图）
- 支出分类分布图（饼图）
- 分类金额统计表格
- Excel 导出功能
- PDF 导出功能
- 按条件筛选后导出

### 4. 添加交易模块 (`AddTransaction`)

**功能定位**：录入新的交易记录，支持图片识别自动填充

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 交易类型选择 | 选择收入或支出 | 切换分类选项列表 |
| 金额输入 | 输入交易金额 | 支持小数点后两位 |
| 分类选择 | 选择交易分类 | 根据类型显示对应分类 |
| 日期选择 | 选择交易日期 | 默认当前日期 |
| 备注填写 | 添加交易备注 | 可选填 |
| 图片上传 | 上传收据图片 | 支持图片预览 |
| OCR 识别 | 自动识别金额和分类 | 使用 Tesseract.js 前端识别 |
| 提交保存 | 保存交易记录 | 验证必填项后提交 |

**实现功能**：
- 交易类型选择（收入/支出）
- 金额输入和验证
- 分类选择（根据类型动态变化）
- 日期选择器
- 备注填写
- 表单验证和提交
- 图片上传和预览
- OCR 文字识别（金额、分类、商户）
- 识别结果自动填充
