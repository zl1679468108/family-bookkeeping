## 已有功能详细说明

### 0. 用户认证模块 (`Auth`)

**功能定位**：实现用户注册、登录、密码找回等完整认证流程

**子功能列表**：

| 功能名称 | API 路由 | 功能描述 | 说明 |
| :--- | :--- | :--- | :--- |
| 用户注册 | `POST /api/auth/register` | 邮箱注册 | 频率限制 60s/10次 |
| 验证码获取 | `GET /api/auth/captcha` | 获取 SVG 验证码 | 防机器人注册 |
| 用户登录 | `POST /api/auth/login` | 邮箱+密码登录 | JWT 认证，频率限制 |
| 切换账号 | `POST /api/auth/switch-account` | 多账号切换 | 频率限制 |
| 忘记密码（邮件链接） | `POST /api/auth/forgot-password` | 发送重置链接到邮箱 | 频率限制 60s/5次 |
| 发送重置验证码 | `POST /api/auth/send-reset-code` | 发送验证码到邮箱 | 频率限制 |
| 验证码重置密码 | `POST /api/auth/reset-password-by-code` | 通过验证码重置密码 | 需邮箱+验证码+新密码 |
| 链接重置密码 | `POST /api/auth/reset-password` | 通过链接重置密码 | 需 token |
| 获取用户信息 | `GET /api/auth/profile` | 获取当前用户资料 | TokenAuthGuard |
| 更新用户信息 | `PUT /api/auth/profile` | 修改昵称等个人信息 | TokenAuthGuard |
| 退出登录 | `POST /api/auth/logout` | 注销当前会话 | TokenAuthGuard |
| 修改密码 | `POST /api/auth/change-password` | 修改登录密码 | TokenAuthGuard |
| 设置当前账本 | `PUT /api/auth/current-book` | 切换当前活跃账本 | TokenAuthGuard |

**实现特点**：
- JWT 令牌认证 + TokenAuthGuard 守卫
- 密码哈希存储（bcrypt）
- 频率限制防护（RateLimitGuard）
- 多用户数据隔离

### 2. 交易记录模块 (`Transactions`)

**路由**：`/transactions`

**功能定位**：管理和查询所有交易记录

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 交易列表 | 展示所有交易记录 | 支持分页或滚动加载 |
| 类型筛选 | 按收入/支出筛选 | 支持全部、收入、支出三种选项 |
| 分类筛选 | 按分类筛选交易 | 根据交易类型动态加载分类选项 |
| 时间范围筛选 | 按日期区间筛选 | 支持 startDate / endDate |
| 关键词搜索 | 按备注/描述搜索 | search / keyword 参数 |
| 金额范围筛选 | 按金额区间筛选 | min_amount / max_amount |
| 排序 | 按金额或日期排序 | 支持升序/降序 |
| 视图切换 | 查看自己/全部交易 | own / all 视图 |
| 快捷添加 | 添加新交易入口 | 跳转至添加交易页面 |

**后端 API**：`/api/transactions`
- `GET /api/transactions` — 查询交易列表（支持 15+ 筛选参数）
- `GET /api/transactions/:id` — 获取单条交易
- `POST /api/transactions` — 创建交易
- `PUT /api/transactions/:id` — 更新交易
- `DELETE /api/transactions/:id` — 删除交易
- `POST /api/transactions/batch` — 批量操作（创建/更新/删除）
- `POST /api/transactions/:id/receipt` — 上传收据图片
- `DELETE /api/transactions/:id/receipt` — 删除收据
