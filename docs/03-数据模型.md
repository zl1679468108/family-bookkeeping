# 03-数据模型

## 数据库表设计

系统包含 12 张核心数据库表，以下为各表的字段定义与业务说明。

---

### 1. 用户表 (`users`)

**功能定位**：存储用户基本信息、认证数据与账本切换状态

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 用户唯一标识 |
| `email` | VARCHAR(255) | UNIQUE, NOT NULL | 用户邮箱，用于登录和通知 |
| `username` | VARCHAR(100) | NOT NULL | 用户昵称，界面显示 |
| `password_hash` | VARCHAR(255) | NOT NULL | 密码哈希值，安全存储 |
| `avatar_url` | TEXT | NULL | 用户头像图片 URL |
| `role` | VARCHAR(20) | NOT NULL, DEFAULT 'user', CHECK IN ('user', 'admin') | 用户角色 |
| `status` | VARCHAR(20) | NOT NULL, DEFAULT 'active', CHECK IN ('active', 'suspended', 'deleted') | 用户状态 |
| `current_book_id` | UUID | NULL | 当前选中的账本 ID（用于多账本切换） |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 账户创建时间 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 最后更新时间 |

**索引**：
- `idx_users_email` ON `users(email)` - 加速邮箱登录查询

**触发器**：
- `update_users_updated_at` - 在更新用户记录时自动刷新 `updated_at` 字段

---

### 2. 密码重置表 (`password_resets`)

**功能定位**：管理密码重置令牌与验证码的创建、验证和过期

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 记录唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 关联的用户 ID |
| `token` | VARCHAR(500) | NOT NULL | 重置令牌，用于邮件链接验证 |
| `code` | VARCHAR(10) | NULL | 6 位数字验证码，用于邮箱验证码重置 |
| `expires_at` | TIMESTAMPTZ | NOT NULL | 令牌/验证码过期时间 |
| `used_at` | TIMESTAMPTZ | NULL | 使用时间（NULL 表示未使用） |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 记录创建时间 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 最后更新时间 |

**索引**：
- `idx_password_resets_token` ON `password_resets(token)`
- `idx_password_resets_user_id` ON `password_resets(user_id)`

**触发器**：
- `update_password_resets_updated_at` - 更新时自动刷新 `updated_at`

---

### 3. 用户会话表 (`user_sessions`)

**功能定位**：管理用户登录会话，支持令牌验证和过期管理

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 会话唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 关联的用户 ID |
| `token_hash` | VARCHAR(255) | UNIQUE, NOT NULL | 令牌哈希值 |
| `expires_at` | TIMESTAMPTZ | NOT NULL | 会话过期时间 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 会话创建时间 |

**索引**：
- `idx_user_sessions_token_hash` ON `user_sessions(token_hash)`
- `idx_user_sessions_user_id` ON `user_sessions(user_id)`
- `idx_user_sessions_expires_at` ON `user_sessions(expires_at)`

---

### 4. 账本表 (`books`)

**功能定位**：支持多账本管理，隔离不同场景的交易数据

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 账本唯一标识 |
| `name` | VARCHAR(100) | NOT NULL | 账本名称（如"家庭账本"、"旅行基金"） |
| `owner_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 账本所有者 ID |
| `is_archived` | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否已归档，归档后不再显示在默认列表 |
| `description` | TEXT | NULL | 账本描述或备注信息 |
| `icon` | VARCHAR(50) | NULL | 账本图标，用于界面展示 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 账本创建时间 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 最后更新时间 |

**索引**：
- `idx_books_owner_id` ON `books(owner_id)`
- `idx_books_is_archived` ON `books(is_archived)`

**触发器**：
- `update_books_updated_at` - 更新时自动刷新 `updated_at`

---

### 5. 账本成员表 (`book_members`)

**功能定位**：存储账本的共享成员信息，支持多人协作记账

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 成员记录唯一标识 |
| `book_id` | UUID | NOT NULL, REFERENCES books(id) ON DELETE CASCADE | 关联的账本 ID |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 成员用户 ID |
| `role` | VARCHAR(10) | NOT NULL, DEFAULT 'member', CHECK IN ('owner', 'member') | 成员角色，决定权限 |
| `joined_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 加入账本的时间 |

**唯一约束**：
- `UNIQUE(book_id, user_id)` - 同一用户不能重复加入同一账本

**索引**：
- `idx_book_members_book_id` ON `book_members(book_id)`
- `idx_book_members_user_id` ON `book_members(user_id)`

---

### 6. 分类表 (`categories`)

**功能定位**：用户级收支分类定义，注册时预设默认分类

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 分类唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 分类所属用户 ID |
| `name` | VARCHAR(50) | NOT NULL | 分类名称（如"餐饮"、"交通"、"工资"） |
| `icon` | VARCHAR(500) | NOT NULL, DEFAULT '📌' | 分类图标，使用 Emoji 或自定义图标 ID |
| `type` | VARCHAR(10) | NOT NULL, CHECK IN ('expense', 'income') | 分类类型：支出 / 收入 |
| `is_default` | BOOLEAN | NOT NULL, DEFAULT false | 是否为系统默认分类 |
| `sort_order` | INTEGER | NOT NULL, DEFAULT 0 | 分类排序序号，数值越小越靠前 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 分类创建时间 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 最后更新时间 |

**索引**：
- `idx_categories_user_id` ON `categories(user_id)`
- `idx_categories_user_name_type` ON `categories(user_id, name, type)` - 唯一索引，防止同用户同类型重名

**触发器**：
- `update_categories_updated_at` - 更新时自动刷新 `updated_at`

---

### 7. 交易记录表 (`transactions`)

**功能定位**：存储所有交易记录，系统核心数据表

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | SERIAL (INT4) | PRIMARY KEY | 交易记录自增 ID |
| `amount` | NUMERIC(10, 2) | NOT NULL | 交易金额 |
| `category` | UUID | REFERENCES categories(id) ON DELETE SET NULL | 关联的分类 ID |
| `type` | VARCHAR(10) | NOT NULL, CHECK IN ('income', 'expense') | 交易类型 |
| `date` | DATE | NOT NULL, DEFAULT CURRENT_DATE | 交易发生日期 |
| `description` | TEXT | NULL | 交易描述/备注 |
| `image_url` | VARCHAR(500) | NULL | 收据/发票图片 URL |
| `user_id` | UUID | REFERENCES users(id) ON DELETE CASCADE | 记录所属用户 ID |
| `book_id` | UUID | REFERENCES books(id) ON DELETE SET NULL | 所属账本 ID |
| `latitude` | NUMERIC(10, 7) | NULL | 纬度，记录交易发生地点 |
| `longitude` | NUMERIC(10, 7) | NULL | 经度，记录交易发生地点 |
| `location_name` | VARCHAR(200) | NULL | 地点名称/地址描述 |
| `poi_id` | VARCHAR(100) | NULL | 高德地图 POI ID，用于地图选点 |
| `brand` | VARCHAR(100) | NULL | 商户/品牌名称 |
| `image_urls` | TEXT | NULL | 收据图片 URL 列表，JSON 格式或逗号分隔 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 记录创建时间 |

**索引**：
- `idx_transactions_user_id` ON `transactions(user_id)`
- `idx_transactions_date` ON `transactions(date)`
- `idx_transactions_type` ON `transactions(type)`
- `idx_transactions_category` ON `transactions(category)`
- `idx_transactions_book_id` ON `transactions(book_id)`
- `idx_transactions_location` ON `transactions(latitude, longitude)` WHERE latitude IS NOT NULL AND longitude IS NOT NULL

---

### 8. 预算表 (`budgets`)

**功能定位**：支持用户设置和跟踪月度各分类预算

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 预算记录唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 预算所属用户 ID |
| `category` | UUID | NOT NULL, REFERENCES categories(id) ON DELETE CASCADE | 预算分类 ID |
| `book_id` | UUID | NULL, REFERENCES books(id) ON DELETE SET NULL | 所属账本 ID |
| `amount` | NUMERIC(10, 2) | NOT NULL | 预算金额上限 |
| `month` | DATE | NOT NULL | 预算月份（格式：YYYY-MM-01） |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 预算设置创建时间 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 最后更新时间 |

**唯一约束**：
- `UNIQUE(user_id, category, month)` - 同一用户同一分类同一月份只有一条预算

**索引**：
- `idx_budgets_user_id` ON `budgets(user_id)`
- `idx_budgets_user_month` ON `budgets(user_id, month)`
- `idx_budgets_book_id` ON `budgets(book_id)`

**触发器**：
- `update_budgets_updated_at` - 更新时自动刷新 `updated_at`

---

### 9. 交易模板表 (`transaction_templates`)

**功能定位**：存储用户预设的记账模板，支持一键快速填充表单

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 模板唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 模板所属用户 ID |
| `name` | VARCHAR(50) | NOT NULL | 模板名称（如"午餐消费"、"通勤车费"） |
| `type` | VARCHAR(10) | NOT NULL, DEFAULT 'expense', CHECK IN ('expense', 'income') | 交易类型 |
| `amount` | NUMERIC(12, 2) | NULL | 预设金额，为空时由用户填写 |
| `category_id` | UUID | REFERENCES categories(id) ON DELETE SET NULL | 关联的分类 ID |
| `note` | VARCHAR(200) | NULL | 预设备注信息 |
| `latitude` | DOUBLE PRECISION | NULL | 模板关联的位置纬度 |
| `longitude` | DOUBLE PRECISION | NULL | 模板关联的位置经度 |
| `location_name` | VARCHAR(100) | NULL | 模板关联的地点名称 |
| `poi_id` | VARCHAR(100) | NULL | 模板关联的 POI 标识 |
| `merchant_name` | VARCHAR(100) | NULL | 商户名称（如餐厅名、店铺名） |
| `book_id` | UUID | REFERENCES books(id) ON DELETE SET NULL | 所属账本 ID |
| `sort_order` | INTEGER | NOT NULL, DEFAULT 0 | 模板排序序号，数值越小越靠前 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 模板创建时间 |

**索引**：
- `idx_transaction_templates_user_id` ON `transaction_templates(user_id)`

---

### 10. 成员位置共享表 (`member_locations`)

**功能定位**：存储账本成员的实时位置信息，支持家庭成员位置共享

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 位置记录唯一标识 |
| `book_id` | UUID | NOT NULL, REFERENCES books(id) ON DELETE CASCADE | 关联的账本 ID |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 成员用户 ID |
| `latitude` | NUMERIC(10, 7) | NOT NULL | 纬度（范围 -90 ~ 90） |
| `longitude` | NUMERIC(10, 7) | NOT NULL | 经度（范围 -180 ~ 180） |
| `is_sharing` | BOOLEAN | NOT NULL, DEFAULT true | 是否正在共享位置，关闭时保留最后位置但不可见 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 位置最后更新时间 |

**唯一约束**：
- `UNIQUE(book_id, user_id)` - 每成员在每账本中只有一条位置记录

**索引**：
- `idx_member_locations_book_id` ON `member_locations(book_id)` WHERE is_sharing = true

---

### 11. 账本邀请码表 (`book_invitations`)

**功能定位**：存储账本邀请码，支持他人通过邀请码加入账本

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | BIGSERIAL | PRIMARY KEY | 邀请记录自增 ID |
| `book_id` | UUID | NOT NULL, REFERENCES books(id) ON DELETE CASCADE | 关联的账本 ID |
| `code` | VARCHAR(32) | NOT NULL, UNIQUE | 邀请码，6 位大写字母+数字 |
| `created_by` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 邀请码创建者用户 ID |
| `used_by` | UUID | REFERENCES users(id) ON DELETE SET NULL | 使用邀请码加入的用户 ID |
| `expires_at` | TIMESTAMPTZ | NOT NULL | 邀请码过期时间 |
| `used_at` | TIMESTAMPTZ | NULL | 邀请码使用时间，NULL 表示未使用 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 邀请码创建时间 |

**索引**：
- `idx_book_invitations_code` ON `book_invitations(code)`
- `idx_book_invitations_book_id` ON `book_invitations(book_id)`
- `idx_book_invitations_active` ON `book_invitations(code, expires_at, used_at)`

---

### 12. 自定义图标表 (`custom_icons`)

**功能定位**：存储用户上传的自定义图标，支持分类和账本使用

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 图标记录唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 图标所属用户 ID |
| `icon_url` | TEXT | NOT NULL | 图标文件 URL 地址 |
| `icon_type` | VARCHAR(20) | NOT NULL, CHECK IN ('category', 'book') | 图标类型：分类图标 / 账本图标 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | 图标上传时间 |

**索引**：
- `idx_custom_icons_user_id` ON `custom_icons(user_id)`
- `idx_custom_icons_type` ON `custom_icons(icon_type)`

**RLS 策略**：
- 用户只能访问自己的图标
