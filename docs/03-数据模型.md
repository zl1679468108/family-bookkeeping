# 03-数据模型

## 数据库表设计

基于项目现有数据库初始化脚本 `database-init.sql`，系统包含以下核心数据库表：

### 1. 用户表 (`users`)

**功能定位**：存储用户基本信息和认证数据

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 用户唯一标识 |
| `email` | VARCHAR(255) | UNIQUE, NOT NULL | 用户邮箱，用于登录和联系 |
| `username` | VARCHAR(100) | NOT NULL | 用户名，用于界面显示 |
| `password_hash` | VARCHAR(255) | NOT NULL | 密码哈希值，安全存储 |
| `created_at` | TIMESTAMP WITH TIME ZONE | DEFAULT NOW() | 账户创建时间 |
| `updated_at` | TIMESTAMP WITH TIME ZONE | DEFAULT NOW() | 最后更新时间 |

**索引**：
- `idx_users_email` ON `users(email)` - 加速邮箱查询

**触发器**：
- `update_users_updated_at` - 在更新用户记录时自动刷新 `updated_at` 字段

**建表语句**：
```sql
CREATE TABLE IF NOT EXISTS users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  username VARCHAR(100) NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 2. 密码重置表 (`password_resets`)

**功能定位**：管理密码重置令牌的创建、验证和过期

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 记录唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 关联的用户 ID |
| `token` | VARCHAR(500) | NOT NULL | 重置令牌，用于验证 |
| `expires_at` | TIMESTAMP WITH TIME ZONE | NOT NULL | 令牌过期时间 |
| `used_at` | TIMESTAMP WITH TIME ZONE | NULL | 令牌使用时间（NULL 表示未使用） |
| `created_at` | TIMESTAMP WITH TIME ZONE | DEFAULT NOW() | 记录创建时间 |

**索引**：
- `idx_password_resets_token` ON `password_resets(token)` - 加速令牌查询
- `idx_password_resets_user_id` ON `password_resets(user_id)` - 加速用户关联查询

**业务规则**：
- 每个令牌有明确的过期时间
- 通过 `used_at` 字段跟踪令牌使用状态
- 用户删除时，相关密码重置记录自动级联删除

**建表语句**：
```sql
CREATE TABLE IF NOT EXISTS password_resets (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  token VARCHAR(500) NOT NULL,
  expires_at TIMESTAMP WITH TIME ZONE NOT NULL,
  used_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 3. 交易记录表 (`transactions`)

**功能定位**：存储所有交易记录，系统核心数据表（已存在）

**表结构**（基于现有表添加外键约束）：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | - | PRIMARY KEY | 交易记录唯一标识 |
| `user_id` | UUID | REFERENCES users(id) ON DELETE CASCADE | 关联的用户 ID（新增约束） |
| `type` | - | - | 交易类型（income/expense） |
| `category` | - | - | 交易分类 |
| `amount` | - | - | 交易金额 |
| `date` | - | - | 交易日期 |
| `note` | - | - | 交易备注 |
| `created_at` | - | - | 记录创建时间 |

**索引**：
- `idx_transactions_user_id` ON `transactions(user_id)` - 加速用户交易查询

**外键约束**：
```sql
ALTER TABLE transactions 
ADD COLUMN IF NOT EXISTS user_id UUID REFERENCES users(id) ON DELETE CASCADE;
```

### 4. 预算表 (`budgets`)

**功能定位**：支持用户设置和跟踪月度预算

**表结构**：

| 字段名 | 数据类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | 预算记录唯一标识 |
| `user_id` | UUID | NOT NULL, REFERENCES users(id) ON DELETE CASCADE | 关联的用户 ID |
| `category` | VARCHAR(50) | NOT NULL | 预算分类 |
| `amount` | DECIMAL(10, 2) | NOT NULL | 预算金额，支持小数 |
| `month` | DATE | NOT NULL | 预算月份（格式：YYYY-MM-01） |
| `created_at` | TIMESTAMP WITH TIME ZONE | DEFAULT NOW() | 记录创建时间 |
| `updated_at` | TIMESTAMP WITH TIME ZONE | DEFAULT NOW() | 最后更新时间 |

**唯一约束**：
- `UNIQUE(user_id, category, month)` - 确保同一用户同一分类同一月份只有一条预算记录

**索引**：
- `idx_budgets_user_id` ON `budgets(user_id)` - 加速用户预算查询
- `idx_budgets_user_month` ON `budgets(user_id, month)` - 加速用户按月查询预算

**触发器**：
- `update_budgets_updated_at` - 在更新预算记录时自动刷新 `updated_at` 字段

**建表语句**：
```sql
CREATE TABLE IF NOT EXISTS budgets (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  category VARCHAR(50) NOT NULL,
  amount DECIMAL(10, 2) NOT NULL,
  month DATE NOT NULL, -- 格式: YYYY-MM-01
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  UNIQUE(user_id, category, month)
);
```

### 关系说明

1. **users → password_resets（一对多）**
   - 一个用户可以有多条密码重置记录
   - 外键：`password_resets.user_id` → `users.id`
   - 级联删除：删除用户时，相关密码重置记录自动删除

2. **users → transactions（一对多）**
   - 一个用户可以有多条交易记录
   - 外键：`transactions.user_id` → `users.id`
   - 级联删除：删除用户时，相关交易记录自动删除

3. **users → budgets（一对多）**
   - 一个用户可以有多条预算记录
   - 外键：`budgets.user_id` → `users.id`
   - 级联删除：删除用户时，相关预算记录自动删除
