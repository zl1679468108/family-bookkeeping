## 1. 产品概述

**产品名称**：家庭记账（安静记账）  
**产品类型**：微信小程序（Taro 框架）  
**核心定位**：极简的家庭/个人记账工具，支持多人协作、多账本、预算管理、消费地图、年度报告等深度功能  
**目标用户**：注重个人财务管理的家庭用户、年轻白领、记账爱好者  

**一句话描述**：用最安静的方式，记录家庭的每一笔。

## 2. Design System — 安静记账 v3.0

### 2.1 设计哲学

```
Style:  Clean, Flat, Calm — 卡片+边框，无阴影
Motto:  "安静的，才长久的"
```

- **无阴影设计**：卡片仅用 0.5px 极细边框区分，不使用投影
- **温润色彩**：主色调鼠尾草绿，温暖不刺眼
- **极简克制**：去除一切装饰元素，仅保留功能性组件
- **留白呼吸**：大量留白让界面透气，每个数字都值得被看见

### 2.6 组件设计原则

**卡片 Card**
- 白色背景 + 0.5px 极细边框（`#EBE7E0`）
- 圆角 7px
- 内边距 12px
- **无阴影**
- 悬停/点击态：背景变 `#F9F7F3`

**按钮 Button**
- 主按钮：全宽、鼠尾草绿 `#5B9A7A` 背景、白字、圆角 6px、字重 600
- 点击态：透明度 0.8
- 次级按钮：`#F9F7F3` 背景、`#666` 文字
- 危险文字按钮：白底红字，0.5px 边框

**分段控制器 SegmentedControl**
- 浅灰底 `#F0EDE6`，圆角 6px，内边距 1.5px
- 激活项：白色背景 + 极微量阴影
- 文字色：未激活 `#B0ADA6` → 激活 `#1A1A1A`

**进度条 ProgressBar**
- 高度 5px，背景 `#F0EDE6`
- 填充色：正常 `#5B9A7A` / 警告 `#D4A34A` / 危险 `#D4785C`

**骨架屏 Skeleton**
- 背景 `#F0EDE6`，圆角 4px
- 脉冲动画：opacity 1 → 0.4 → 1，1.5s 循环

**输入框 Input**
- 背景 `#F5F2ED`，1px 边框 `#EBE7E0`
- 圆角 6px，高度 44px
- Focus 态：边框变 `#5B9A7A`

## 3. App Shell 全局框架

### 3.1 导航栏 (NavHeader)

**高度**：44px（自动处理 safe area）  
**三栏布局**：
- 左(40px)：返回按钮或关闭按钮（× 图标）或自定义内容
- 中：页面标题，居中对齐，字号 15px，字重 600
- 右(40px)：操作按钮（搜索、模板、筛选等）或自定义内容

**样式**：白色背景，无底部边框，透明状态栏

### 3.2 底部 TabBar（自定义）

**高度**：约 56px + safe-area  
**布局结构**：

```
┌─────────┬─────────┬─────────┬─────────┐
│  首页   │  流水   │  记账   │  统计   │  我的   │
│  (图标)  │  (图标)  │  (FAB)  │  (图标)  │  (图标)  │
│  首页   │  流水   │    ＋   │  统计   │  我的   │
└─────────┴─────────┴─────────┴─────────┘
```

**关键特性**：
- 居中有 **FAB（浮动操作按钮）**：白色圆形、鼠尾草绿边框/文字、"＋" 图标
- 普通 Tab 项：图标(22px) + 文字(10px, `#B0ADA6`)
- 激活态 Tab 项：图标(22px) + 文字(10px, `#5B9A7A`)
- FAB 不改变激活态判定

## 5. 全局交互规范

### 5.1 弹窗 (ConfirmDialog)

所有确认/删除操作统一使用 ConfirmDialog 组件。

```css
Dialog 样式:
- 居中半透明遮罩 (黑色 50% opacity)
- 白色卡片, 圆角 10px, 宽度约 300px
- 标题 + 描述文字 + 取消按钮 + 确认按钮
- 确认按钮: 危险操作红色 / 普通操作绿色
- 从底部弹出动画 (slide-up 300ms)
```

### 5.2 Toast 提示

- 轻量操作反馈：顶部居中，2s 自动消失
- 成功：绿色背景
- 错误：红色背景

### 5.3 加载与空状态

| 状态 | 组件 | 使用场景 |
|---|---|---|
| 加载中 | Skeleton / PullRefresh | 数据请求中 |
| 加载失败 | EmptyState | 网络错误或服务器异常 |
| 无数据 | EmptyState | 列表为空 |
| 搜索无结果 | EmptyState | 搜索匹配不到 |

**EmptyState 组件**：
- 居中对齐
- 灰色小图标
- 标题文字 (字号 14px, 字重 600)
- 描述文字 (字号 11px, `#B0ADA6`)
- 可选操作按钮

### 5.4 日期/月份选择

**统一使用原生 Picker 弹选**：
- 年月选择 → `Picker mode="date" fields="month"`
- 日期选择 → `Picker mode="date"`
- **禁止**左右箭头切换月份

### 5.5 上拉加载

- 使用 ScrollView 的 onScrollToLower 回调
- 底部显示 "加载中…" 或 "— 没有更多了 —"

### 5.6 页面转场

- 所有页面进入：轻微淡入 (200ms)
- 弹窗出现：底部滑入 (300ms)

## 6. 用户核心流程

### 6.1 新用户入门
```
启动 App → 登录页 → 注册账号 → 首页(空状态) 
→ 点击底部 FAB "+" → 记一笔 → 选择支出/收入 
→ 输入金额 → 选分类 → 选日期 → 填备注 → 保存 
→ 回到首页(有数据)
```

### 6.2 日常记账
```
首页查看概况 → 点击 FAB 快速记账 → 保存 → 回到首页 
→ 切换到"流水"Tab 查看详情 → 筛选/搜索 
→ 点击某条交易编辑或删除
```

### 6.3 预算管理
```
首页 → 预算推送(超支/预警) → 预算管理页 
→ 设置总预算和各分类预算 → 首页实时显示进度
```

### 6.4 数据回顾
```
"统计"Tab → 切换时间范围 → 查看趋势图+分类占比 
→ "我的" → 消费日历 → 按天查看 → "年度报告"(未来)
```

### 6.5 多账本协作
```
"我的" → 账本管理 → 创建新账本(如"旅行") 
→ 选择账本 → 所有数据自动切换 → 可添加成员协作
```
