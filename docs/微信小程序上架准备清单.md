# 微信小程序上架准备清单

> 适用：静记 Taro 小程序提交审核前准备
> 状态：已回填生产域名；微信后台配置和审核账号仍需提交前人工填写

## 1. 审核备注模板

```text
本小程序为家庭记账工具「静记」，用于个人/家庭成员记录日常收入、支出、预算和账本数据，不涉及金融理财、贷款、支付、投资、虚拟币等业务。

测试账号：
邮箱：xxxx@example.com
密码：xxxxxx

测试路径：
1. 使用测试账号登录
2. 首页查看账本概览
3. 进入“记一笔”新增支出或收入
4. 进入“流水”查看记录
5. 进入“我的”查看用户协议、隐私政策、联系客服、注销账号入口

说明：
- 小程序已提供《用户协议》和《隐私政策》
- 注册前需勾选同意协议
- 位置权限仅用于用户主动记录交易地点
- 相册/相机仅用于用户主动上传头像、账本图标或交易附件
- 用户可在“我的”页面主动注销账号
```

## 2. 隐私保护指引要点

```text
1. 邮箱地址
用途：用于账号注册、登录、找回密码和账号识别。

2. 账号密码
用途：用于账号登录认证。服务端仅保存加密后的密码摘要，不保存明文密码。

3. 昵称
用途：用于账本成员展示、个人资料展示。

4. 头像
用途：用于用户个人资料展示。用户可主动上传或修改。

5. 位置信息
用途：用户主动使用“交易地点”功能时，用于记录该笔交易发生地点。

6. 图片或相册信息
用途：用户主动上传头像、账本图标、分类图标或交易附件时使用。

7. 用户填写的内容
用途：用于保存账本名称、账本描述、交易备注、分类名称、模板名称等记账相关内容。
```

建议补充一句：

```text
不用于广告投放、营销推荐或第三方画像，仅用于本小程序核心记账功能。
```

## 3. 服务器域名

微信后台「开发管理 → 开发设置 → 服务器域名」建议填写：

```text
request 合法域名：
https://zlspace.site

uploadFile 合法域名：
https://zlspace.site

downloadFile 合法域名：
https://zlspace.site
https://fvggqgeiwewsjojargxe.supabase.co
```

注意：
- 正式审核前要使用 HTTPS，不要填 localhost。
- `zlspace.site` 是生产后端（自建 CVM + Nginx），所有接口请求、文件上传、文件下载均经此后端代理。
- `https://fvggqgeiwewsjojargxe.supabase.co` 是 Supabase 存储公共域名：交易小票图、自定义图标经后端 `getPublicUrl()` 返回其直链，`<image>` 组件在真机显示这些图必须在 downloadFile 合法域名中（request/uploadFile 不需要它）。

生产接口地址（小程序 `TARO_APP_API_BASE_URL`）：

```text
https://zlspace.site/api
```

PC Web 生产地址：

```text
https://zlspace.site
```

## 5. 提交前最后检查

1. 后端代码已接入微信内容安全检测；提交前确认生产环境已配置 `WECHAT_APPID`、`WECHAT_SECRET`、`WECHAT_MSG_SEC_CHECK_ENABLED=true`。
2. 微信后台已按第 3 节配置服务器域名。
3. 微信开发者工具关闭「不校验合法域名」后再跑一遍真机或模拟器。
4. 准备一个审核专用账号，不要用主账号。
5. 审核备注带测试账号和测试路径。
6. 代码版本备注写清楚功能范围。
