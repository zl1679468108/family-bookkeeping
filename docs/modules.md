# 家庭记账应用 - 功能模块文档

---

## 模块总览

### 前端模块（React）

| 模块名称 | 路径 | 主要功能 |
| :--- | :--- | :--- |
| 仪表板 | `/` | 财务概览、统计卡片、最近交易 |
| 交易记录 | `/transactions` | 交易列表、筛选查询 |
| 统计报表 | `/reports` | 图表分析、分类统计、导出功能 |
| 添加交易 | `/add` | 新建交易记录 |

### 后端模块（NestJS）

| 模块名称 | 路径 | 主要功能 |
| :--- | :--- | :--- |
| 交易管理 | `/api/transactions` | 交易的增删改查 |
| 数据导出 | `/api/export` | Excel/PDF 文件生成 |
| 健康检查 | `/api/health` | 服务状态检查 |

---

## 模块详细说明

### 1. 仪表板模块 (`Dashboard`)

**功能定位**：提供用户财务状况的快速概览

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 余额统计 | 展示当前账户余额 | 显示所有收支后的净额 |
| 收入统计 | 展示累计总收入 | 统计所有收入类型交易 |
| 支出统计 | 展示累计总支出 | 统计所有支出类型交易 |
| 最近交易 | 展示最近5条交易记录 | 按时间倒序排列 |
| 快捷操作 | 提供快速导航按钮 | 跳转报表页、添加交易页 |

---

### 2. 交易记录模块 (`Transactions`)

**功能定位**：管理和查询所有交易记录

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 交易列表 | 展示所有交易记录 | 支持分页或滚动加载 |
| 类型筛选 | 按收入/支出筛选 | 支持全部、收入、支出三种选项 |
| 分类筛选 | 按分类筛选交易 | 根据交易类型动态加载分类选项 |
| 快捷添加 | 添加新交易入口 | 跳转至添加交易页面 |

---

### 3. 统计报表模块 (`Reports`)

**功能定位**：提供数据可视化分析

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 支出趋势图 | 展示支出随时间变化趋势 | 支持时间范围选择（6个月/3个月/1年） |
| 支出分类饼图 | 展示各分类支出占比 | 直观展示消费结构 |
| 分类金额统计 | 展示各分类具体金额 | 显示金额和占比百分比 |
| 导出 Excel | 导出交易数据为 Excel | 支持筛选导出 |
| 导出 PDF | 导出交易数据为 PDF | 支持筛选导出 |

---

### 4. 添加交易模块 (`AddTransaction`)

**功能定位**：录入新的交易记录

**子功能列表**：

| 功能名称 | 功能描述 | 说明 |
| :--- | :--- | :--- |
| 交易类型选择 | 选择收入或支出 | 切换分类选项列表 |
| 金额输入 | 输入交易金额 | 支持小数点后两位 |
| 分类选择 | 选择交易分类 | 根据类型显示对应分类 |
| 日期选择 | 选择交易日期 | 默认当前日期 |
| 备注填写 | 添加交易备注 | 可选填 |
| 图片上传 | 上传收据图片 | 支持图片识别（待实现） |
| 提交保存 | 保存交易记录 | 验证必填项后提交 |

## 后端模块详细说明

### 1. 交易管理模块 (`TransactionModule`)

**功能定位**：提供交易数据的增删改查 API

**API 接口**：

| 方法 | 路径 | 功能描述 |
| :--- | :--- | :--- |
| GET | `/api/transactions` | 获取所有交易记录 |
| GET | `/api/transactions/:id` | 获取单个交易记录 |
| POST | `/api/transactions` | 创建新交易 |
| PUT | `/api/transactions/:id` | 更新交易记录 |
| DELETE | `/api/transactions/:id` | 删除交易记录 |

**查询参数**：

| 参数 | 类型 | 描述 |
| :--- | :--- | :--- |
| `type` | string | 交易类型（income/expense） |
| `category` | string | 分类 |
| `startDate` | string | 开始日期（YYYY-MM-DD） |
| `endDate` | string | 结束日期（YYYY-MM-DD） |

---

### 2. 导出模块 (`ExportModule`)

**功能定位**：提供 Excel 和 PDF 文件导出功能

**API 接口**：

| 方法 | 路径 | 功能描述 |
| :--- | :--- | :--- |
| GET | `/api/export/excel` | 导出 Excel 文件 |
| GET | `/api/export/pdf` | 导出 PDF 文件 |

**查询参数**：

| 参数 | 类型 | 描述 |
| :--- | :--- | :--- |
| `type` | string | 交易类型（income/expense） |
| `category` | string | 分类 |
| `startDate` | string | 开始日期（YYYY-MM-DD） |
| `endDate` | string | 结束日期（YYYY-MM-DD） |

**文件格式**：

| 格式 | 内容 |
| :--- | :--- |
| Excel | 包含日期、类型、分类、金额、备注列，支持样式和筛选 |
| PDF | 包含标题、导出时间、交易列表、统计摘要 |
