# 家庭记账应用 - 需求文档

## 项目概述

家庭记账应用是一个前后端分离的现代化财务管理工具，包含 React 前端和 NestJS 后端。前端负责用户界面和交互，后端提供数据处理和文件导出功能。

**技术架构**：
- 前端：React 18 + TypeScript + Tailwind CSS
- 后端：NestJS + Supabase
- 部署：前端部署到静态托管，后端部署到腾讯云 CloudBase 云托管
