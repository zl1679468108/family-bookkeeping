# 01-项目结构

## 项目整体架构

静记采用前后端分离架构，包含 Web 前端、NestJS 后端和微信小程序三个部分：

```
family-bookkeeping/
├── frontend/              # 前端应用（React + TypeScript）
├── backend/               # 后端服务（NestJS + Supabase）
├── taro/                  # 微信小程序（Taro + wx.cloud）
├── config/                # 配置文件
├── scripts/               # 部署脚本
├── docs/                  # 文档目录
├── .agents/               # Agent 配置
├── .mimocode/             # MiMo 配置
├── .trae/                 # Trae 配置
├── .workbuddy/            # WorkBuddy 配置
├── cloudbaserc.json       # CloudBase 配置
└── skills-lock.json       # Skills 锁定文件
```

### 技术栈
- **React 18** - 前端框架

- **React Router DOM v6** - 路由管理
- **ECharts** - 图表库（趋势图、饼图）
- **AMap** - 高德地图集成
- **CloudBase** - 部署平台（非 Vercel）

### 部署方式
前端通过 CloudBase 静态托管部署，不使用 Vercel。

## 部署架构

### 开发环境架构
```
┌──────────────┐     HTTP      ┌──────────────┐     SQL      ┌───────────┐
│  前端 React  │ ────────────> │  NestJS API  │ ──────────> │ Supabase  │
│  localhost   │ <──────────── │  localhost   │ <────────── │ PostgreSQL│
└──────────────┘               └──────────────┘             └───────────┘
```

### 生产环境架构
```
┌──────────────┐              ┌──────────────┐              ┌───────────┐
│   用户浏览器   │ ───────────> │ CloudBase    │ ──────────> │ Supabase  │
│              │              │ 云托管(NestJS)│              │ PostgreSQL│
└──────────────┘              └──────────────┘              └───────────┘
     │                             │
     │ HTTPS                        │ HTTPS
     ▼                             ▼
┌──────────────┐              ┌──────────────┐
│  CloudBase   │              │ CloudBase    │
│ 静态托管(前端)│              │ 容器服务     │
└──────────────┘              └──────────────┘
```

### 小程序架构
```
┌──────────────┐     wx.cloud     ┌──────────────┐
│  微信小程序   │ ───────────────> │ CloudBase    │
│  (Taro)      │                  │ 云函数/数据库 │
└──────────────┘                  └──────────────┘
```
