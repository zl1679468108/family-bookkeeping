# 01-项目结构

## 项目整体架构

静记采用前后端分离架构：

```
family-bookkeeping/
├── frontend/              # 前端应用（React）
├── backend/               # 后端服务（NestJS）
└── docs/                  # 文档目录
```

## 前端目录结构和技术栈

### 目录结构
```
frontend/
├── public/                # 静态资源
├── src/                   # 源代码
│   ├── components/         # React 组件
│   │   ├── Button/        # 按钮组件
│   │   ├── ChartCard/     # 图表卡片（ECharts）
│   │   ├── CategoryRanking/ # 分类排行表
│   │   ├── DateRangeFilter/ # 时间范围筛选器
│   │   ├── FilterBar/     # 筛选栏
│   │   ├── Form/          # 表单组件
│   │   ├── Header/        # 头部组件
│   │   ├── ImageUploader/ # 图片上传
│   │   ├── Layout/        # 布局组件
│   │   ├── Sidebar/       # 侧边栏
│   │   ├── StatCard/      # 统计卡片
│   │   ├── TransactionsList/ # 交易列表
│   │   └── ui/            # UI 基础组件
│   ├── pages/              # 页面组件
│   │   ├── Dashboard.tsx   # 仪表板
│   │   ├── Transactions.tsx # 交易记录

├── vercel.json
```

### 技术栈
- **React 18** - 前端框架
- **TypeScript** - 类型安全
- **Tailwind CSS** - 样式框架
- **React Query (@tanstack/react-query v5.20.3)** - 状态管理
- **React Router DOM v6.22.3** - 路由管理
- **date-fns v2.30.0** - 日期处理
- **lucide-react v0.382.0** - 图标库
- **echarts v5.6+** - 图表库（趋势图、饼图）
- **echarts-for-react v3.0+** - ECharts React 封装

## 执行命令

### 前端开发命令
```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 开发环境启动
npm start                    # 启动开发服务器 (PORT=3001)

# 生产环境启动
npm run start:prod          # 生产环境启动 (PORT=3002)

# 构建
npm run build               # 开发环境构建
npm run build:prod          # 生产环境构建

# 测试和代码质量
npm test                    # 运行测试
npm run lint                # 代码检查
npm run lint:fix            # 自动修复代码问题
```

### 后端开发命令
```bash
# 进入后端目录
cd backend

# 安装依赖
npm install

# 开发环境启动
npm start                    # 启动开发服务器 (NODE_ENV=development)

# 生产环境启动
npm run start:prod          # 生产环境启动 (NODE_ENV=production)

# 构建
npm run build               # 开发环境构建
npm run build:prod          # 生产环境构建

# 代码质量和测试
npm run format              # 代码格式化
npm run lint                # 代码检查
npm test                    # 运行测试
npm run test:watch          # 测试观察模式
npm run test:cov            # 测试覆盖率
```

### Docker 部署命令
```bash
# 构建 Docker 镜像
cd backend
docker build -t family-bookkeeping-api .

# 运行容器
docker run -p 3000:3000 --env-file .env family-bookkeeping-api

# 使用 Docker Compose
docker-compose up
```

## 部署架构

### 开发环境架构
```
┌──────────────┐     HTTP      ┌──────────────┐     SQL      ┌───────────┐
│  前端 React  │ ────────────> │  NestJS API  │ ──────────> │ Supabase  │
│  localhost   │ <──────────── │  localhost   │ <────────── │ PostgreSQL│
└──────────────┘               └──────────────┘             └───────────┘
```

### 生产环境架构
```
┌──────────────┐              ┌──────────────┐              ┌───────────┐
│   用户浏览器   │ ───────────> │ CloudBase    │ ──────────> │ Supabase  │
│              │              │ 云托管(NestJS)│              │ PostgreSQL│
└──────────────┘              └──────────────┘              └───────────┘
     │                             │
     │ HTTPS                        │ HTTPS
     ▼                             ▼
┌──────────────┐              ┌──────────────┐
│  CDN/静态托管 │              │ CloudBase    │
│  (前端 React) │              │ 容器服务     │
└──────────────┘              └──────────────┘
```
