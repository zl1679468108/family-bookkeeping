五、优化建议全部纳入实现

1. 夜间模式
CSS 变量切换：深色底 #1A1A1A / 卡片 #252525 / 文字反转。跟随系统设置或应用内开关。
2. 触觉反馈
保存成功/删除确认/预算超限时调用 wx.vibrateShort()。
3. 下拉刷新+上拉加载
首页/流水页 enablePullDownRefresh，20条后分页加载。
4. 金额输入格式化
输入 5800 → 显示 ¥58.00，自动右对齐小数点。
5. 搜索增强
备注模糊搜索 + 金额范围筛选 + 高亮匹配文字。
6. 页面过渡动画
Tab 切换 fade 200ms / 二级页右滑推入 / 返回左滑。
7. 样式抽离为 SCSS class
内联 style={{}} → 公共 SCSS class，减少运行时开销。
8. 分类图标统一管理
category → emoji 映射表，单文件维护所有分类图标
9. 首页快捷操作
余额卡片下横向滚动：本周报表/月度预算/常用分类快捷记账
10. 性能优化
长列表虚拟列表 + 图片 lazy-load + onLaunch 预加载首页数据
