设计理念

记账工具不该喧哗。
安静、可信赖、融入日常 —
像一个随身携带的笔记本。

卡片即内容 — 白色卡片 + 细边框，不抢注意力
色彩克制 — 主色仅用于交互元素

额外优化建议

除了视觉重设计，以下优化可以使小程序体验更好

1. 夜间模式支持
基于 CSS 变量切换，新增 dark 主题配色：深色背景 #1A1A1A、卡片 #252525、文字反转。通过系统设置或应用内开关切换。
2. 触觉反馈
关键操作（记一笔保存成功、删除确认、预算超限提醒）调用微信 wx.vibrateShort() 提供轻微震动反馈。
3. 下拉刷新 & 上拉加载
首页和流水页启用下拉刷新（enablePullDownRefresh），刷新动画用主色。流水列表超过 20 条启用上拉分页加载。
4. 金额输入优化
记账页金额自动格式化（输入 5800 → 显示 ¥58.00），避免用户手动输入小数点。右侧固定显示 .00。
5. 搜索功能增强
流水页搜索支持按备注模糊搜索、按金额范围筛选，搜索结果高亮匹配文字。
6. 页面过渡动画
Tab 切换使用淡入淡出（opacity 0→1, 200ms），避免生硬跳变。二级页面使用右滑推入/左滑返回动画。
7. 样式抽离为 CSS 类
当前大量样式写在 TSX 的 style={{}} 中，改为 SCSS class 引用。好处：减少运行时开销、统一修改、压缩体积。
8. 分类图标统一管理
建立 emoji 映射表（category → emoji），不用每个地方硬编码。支持用户自定义分类时选择 emoji。
9. 首页快捷操作
余额卡片下方添加常用快捷操作横向滚动条：本周报表、月度预算、最近常用分类快捷记账。
10. 性能优化
长列表使用虚拟列表（VirtualList）；图片使用 lazy-load；首页数据预加载（在 app.onLaunch 中提前请求）。
